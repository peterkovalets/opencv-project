# Ознакомительная практика

### Требования для сборки из исходного кода
1. JDK (Java Development Kit);
2. Git (опционально, так как возможен вариант скачивания zip-архива репозитория).

### Инструкции по сборке приложения
Клонировать репозиторий (если был установлен Git):
```shell
git clone https://github.com/peterkovalets/opencv-project
```
Находясь в каталоге проекта, выполнить (mvnw.exe для Windows):
```shell
./mvnw compile package
```
Перейти в каталог target внутри проекта и выполнить:
```shell
java -jar opencv-project-1.0-SNAPSHOT.jar
```

### Инструкции по использованию
Как только было получено изображение путем загрузки файла или снимком с камеры, возможно выполнение следующих функций:
1. Извлечение красного, зеленого или синего канала изображения;
2. Получение изображения в оттенках серого;
3. Выполнение вращения изображения;
4. Рисование прямоугольника на изображении синим цветом.
